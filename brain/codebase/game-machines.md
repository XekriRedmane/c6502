# The games' machines in C++ and their checks

- cpp/src/sim/apple2.h (Zork), lode_runner.h, ali_baba.h, and disk2.h (G5 of step 9, 27 Nov 2026) were ported from sim/apple2.py, lode_runner.py, ali_baba.py, and disk2.py. cpp/src/sim/games.h holds the scripts and the setups the Python tests played them in, and `c6502cpp game-run GAME SCRIPT [--exe PATH]` plays one and writes its events. The doctest cases are cpp/tests/test_zork_interpreter_sim.cpp, test_lode_runner_sim.cpp, test_ali_baba_sim.cpp, and test_disk2.cpp, gated on the game variables with `doctest::skip(bool)` at registration, so a run without the files reports them as skipped rather than passed. All 22 take about 22 seconds.
- The machines run their own loops over `Cpu::step` and decode each instruction's soft-switch access before it runs, as the Python ones did. The CPU's read and write callbacks would also see `JMP ($C0xx)` and the opcode fetch, which the Python decoding left out, and `Cpu::run` has no stop check between an instruction and the next cycle check, where the Python machines checked their `stop`. Every comparison passed on the first build with that design.
- tools/compare_game_machines.py compared `game-run`'s text with the same text from the Python machines until group R of step 9 removed both it and sim/. `game-run --exe` without `--events` runs a C program until it has made as many events as the original makes.
- The examples' linker scripts place sections by object file name (`decode.o(.text ...)` in interpreter.ld), so a build that names its objects `zork-decode.o` links a different program, which in G5 made 8 more calls than the original. Build each example's objects in a directory of their own, named after their units.
- No script of the three games executes an undefined opcode, on the original or on the C program.
- Ali Baba's disk calls that haven't returned are in `pending_returns_`, by return address. `run` records the returns there before it dispatches the address's hook, and the delay loops treat a pending address as a hook. Until 27 Nov 2026 each return was a hook that wrapped the one at its address and replaced itself in `hooks`, which dropped a later call's return when an earlier call to the same address returned first, and missed a return to $0000 from a call at $FFFD. Both have doctest cases that run without the game files.
- Zork's `text` line in the comparison is a CRC of `text()`, which strips each row's trailing spaces, so it couldn't show the old rows that a window past column 40 lengthened with spaces. The screen is now 40 by 24, and a scroll or HOME with a window past it throws, which no script does.
