# Porting Python tests by their recorded calls

- `tools/record_test_calls.py record --out C:/w/rec tests/test_x.py ...` records each call a test makes itself of a function `check-captures` runs, and lists its other direct calls into the compiler (`index.json`, per test: `calls`, `direct`, `end_to_end`, `unrecordable`). `cpp --to cpp/tests/test_x_calls.cpp tests/test_x.py` writes the cases. cpp/README.md, "The unit tests' recorded calls", has the rules. G6 ran eight recorders in parallel, each into its own directory, and merged the indexes.
- The wrapper records a call only when the caller's frame is a tests.* module, so a test helper such as `_run` counts and a pass called from another pass doesn't. The profile hook does the same for the "direct" list, which is what decides whether a test can go: a test is safe to remove only when `direct` is empty or holds only calls that build or read the recorded call's objects (`binutils.elf`, `CoalesceResult.resolve`, `InterferenceGraph.add_edge`, `ir_check.enable`).
- The dedup against existing cases matches recorded cases of earlier steps (literals holding the name, args, input, output) and can't see hand-written C++ cases. cpp/tests/test_asm_helpers.cpp is a hand port of test_asm_aliasing.py, test_asm_liveness.py, and test_asm_cfg.py, never checked test by test, so those tests stayed.
- Things that needed more than the record: a test that passes `None` for a table the C++ codec takes by value (record with empty tables), a Python ValueError that C++ throws as InternalError, a pass whose Python version runs the IR checks inside it (asm_to_asm2's `translate_program`), a Python subclass of an IR base (unportable), and a module-global flag such as `ir_check.enable` that the record's context doesn't carry.
- C:/w/g6/prune.py (scratch, not committed) removed tests by ID with AST spans, then the classes left empty, then module-level names and imports nothing used, iterating, and kept each file's line endings. Its first version walked into the skipped node's children and kept every name, since a name's own `Store` counted as a use. `uvx pyflakes` runs without installing pyflakes and checks the result.
- 245 G6 tests are left (docs/cpp_port.md, "G6's modules"). The cheapest next piece is a helper record kind for `may_alias` and asm_liveness's predicates (operands or an instruction list and an index, the context with the pointer proof, a bool), which would take test_asm_aliasing.py and test_asm_liveness.py.
