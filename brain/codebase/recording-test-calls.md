# Porting Python tests by their recorded calls

- `tools/record_test_calls.py record --out C:/w/rec tests/test_x.py ...` records each call a test makes itself of a function `check-captures` runs, and lists its other direct calls into the compiler (`index.json`, per test: `calls`, `direct`, `end_to_end`, `unrecordable`). `record_test_calls.py cpp --out C:/w/rec --to cpp/tests/test_x_calls.cpp tests/test_x.py` writes the cases. cpp/README.md, "The unit tests' recorded calls", has the rules and the record kinds. G6 ran eight recorders in parallel, each into its own directory, and merged the indexes.
- The wrapper records a call only when the caller's frame is a tests.* module, so a test helper such as `_run` counts and a pass called from another pass doesn't. The profile hook does the same for the "direct" list, which decides whether a test can go: a test is safe to remove only when `direct` is empty or holds only calls that build or read the recorded call's objects (`binutils.elf`, `CoalesceResult.resolve`, `InterferenceGraph.add_edge`, `ir_check.enable`).
- A module-global flag such as `ir_check.enable` isn't carried in a record's context, so a test that sets it needs a case written by hand.
- A script that removes tests by their AST spans must skip the removed node's children, or each name's own `Store` counts as a use and nothing is removed. `uvx pyflakes` checks the result without installing pyflakes.
- Re-record before trusting an old index's `direct` list. G6's index predated `linked_text`'s move to `c6502cpp objdump`, so tests it listed as calling `disassemble` were already end to end.
- A test that builds IR the dump can't hold (a `StaticVariable` with one `IntInit` in place of a list) can be fixed to build valid IR, and then its call records.
- A test that inspects TAC can stay end to end. `eval(_run_stage("tac", preprocess(src), optimize=o), vars(tac_ast))` reads `compile.py --tac`'s `pretty` text back into `tac_ast` objects, equal to Python's own TAC for the programs tried.
- A private C++ helper that a Python test called can be moved out of its unnamed namespace and declared in the pass's header for a hand-written case. Close the unnamed namespace before the function and reopen it after, since the rest of the file's helpers stay visible to it.
- In doctest, `CHECK(ptr != nullptr)` on a `std::shared_ptr` of a type without `operator<<` fails to compile under MSVC. Compare `.get()`. A test-local wrapper named like a passes function (`may_alias`) gets an ambiguous call through argument-dependent lookup on `AsmContext`, so name it differently.
- Things that broke records in G7: tests give a plain dict as the symbol table (wrap it in a `SymbolTable` sharing the dict), `StaticAttr(initial_value=None)` (the codec needs `NoInitializer()`, so fix the test), a Python `IdAttr` subclass (use `LocalAttr`), `preprocess(src)` called alone (its stage call needs args; don't record it, the parse record holds its output), c99_to_tac's `translate_program(prog)` without tables (it type-checks inside; record the type check and the call with tables), and `optimize_program(prog)` without symbols (the C++ runner takes a missing arg as null).
- The dedup against older cases (`_record_parts`) finds step 5's `check_stage_case` cases too, so most TAC pass tests needed no new case. Check the C++ side with `c6502cpp check-captures <dir>` on one test's records to see which part differs.
- A test's patch of a Python estimate (row_address_tables' `_saving`) can be recorded as an extra keyword of the stage call that the C++ runner reads, and the end-to-end tests that forced the Python pipeline were rewritten with programs the real estimate accepts.
- This note serves groups G6 to G8 of step 8, and group R deletes it once no Python test is left to port.
